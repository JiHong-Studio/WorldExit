# WorldEditPE

本文件为模组包内占位说明，完整文档见项目根目录 [`README.md`](../../../README.md)。

## 快速指令速查

- 帮助：`=help`
- 选区：`=pos1` / `=pos2` / `=wand` / `=sel` / `=desel`
- 区域：`=set <方块>` / `=replace [源] <目标>` / `=walls` / `=outline` / `=line`
- 几何：`=cyl` / `=hcyl` / `=sphere` / `=hsphere` / `=pyramid` / `=cone`
- 剪贴板：`=copy` / `=cut` / `=paste` / `=stack` / `=rotate` / `=flip`
- 工具：`=fill` / `=fillr` / `=drain` / `=brush` / `=size` / `=mask`
- 历史：`=undo` / `=redo` / `=clearhistory`
